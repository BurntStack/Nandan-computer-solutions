NANDAN COMPUTER SOLUTIONS — STATIC WEBSITE
===========================================

QUICK START
1. Extract the ZIP.
2. Open index.html in a browser to preview, or upload the complete contents of this folder to your Hostinger public_html directory.
3. Keep the assets folder and courses folder in their original locations.
4. For best results, test using a local server (VS Code Live Server) before publishing.

PAGES
- index.html
- about.html
- courses.html
- projects.html
- internships.html
- contact.html
- courses/<course>.html (individual course pages with course preselected)

IMPORTANT
This is a static frontend. It does not silently store enquiries in a database or send email on its own. The visitor must press Send in WhatsApp. To store leads centrally or email them automatically, connect a backend/API or a form service and configure it before launch.

BRANDING
The logo is cropped from the supplied Nandan business-card artwork. Supplied promotional posters are included in assets/.
Some visual typography is loaded from Google Fonts; if unavailable, the site falls back to system fonts.

EDITING
- Update course descriptions and course list in app.js.
- Update phone/email/address in app.js.
- Update colours and layout in styles.css.
